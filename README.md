# Поисковая система для документов

## Описание

Инструмент для индексации и полнотекстового поиска по документам различных форматов:
- **Текстовые документы:** `.doc`, `.docx`
- **Таблицы:** `.xls`, `.xlsx`
- **PDF:** `.pdf`
- **Архивы:** `.zip`, `.rar`, `.7z` (с рекурсивным обходом вложений)

---

## Установка

```bash
# 1. Клонировать проект
cd testovoe_aton2

# 2. Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Установить утилиты для архивов (опционально)
sudo apt-get install rar unrar p7zip-full  # Ubuntu/Debian
```

## Команды поиска

### Интерактивный режим
```bash
python search.py
```

Доступные команды:
- `/exit` — выход
- `/help` — справка по запросам
- `/stats` — статистика по типам файлов
- `/list` — список документов в индексе

### Прямой поиск
```bash
python search.py "финансовый"
python search.py "договор"
python search.py "техническое задание"
```

## Результаты работы

### CSV файл (`output/documents_index.csv`)

Содержит для каждого файла:
- `file_path` — путь к файлу
- `file_name` — имя файла
- `file_type` — расширение
- `file_size` — размер в байтах
- `content_preview` — первые 1000 символов

### База данных (`output/search.db`)

- **Движок:** SQLite с расширением FTS5
- **Таблица:** `documents` (виртуальная FTS5)
- **Поля:** `file_path`, `file_name`, `file_type`, `content`
- **Токенизатор:** `unicode61` (поддержка русского языка)

### Пример поиска

```
🔍 ПОИСК: 'финансовый'
======================================================================
✅ НАЙДЕНО: 3 ДОКУМЕНТА

1. doc_1_finance.docx [docx]
   → **финансовый** отчёт о деятельности компании...

2. doc_1_finance.pdf [pdf]
   → анализ **финансовых** показателей...

3. doc_1_finance.xlsx [xlsx]
   → **финансовый** бюджет на следующий квартал...
```

## Устранение проблем

### Ошибка: `no such tokenizer: russian`
**Решение:** Исправлено в коде — используется `unicode61`

### Ошибка: `rar: command not found`
**Решение:** RAR архивы пропускаются, остальные форматы работают

### Пустой результат поиска
**Решение:** Проверьте, что сначала запущен `crawler.py` и `create_db.py`
