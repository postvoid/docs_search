# Поисковая система для документов

## Описание

Инструмент для генерации, индексации и полнотекстового поиска по документам различных форматов:
- **Текстовые документы:** `.doc`, `.docx`
- **Таблицы:** `.xls`, `.xlsx`
- **PDF:** `.pdf`
- **Архивы:** `.zip`, `.rar`, `.7z` (с рекурсивным обходом вложений)

---

## Установка

```bash
# 1. Клонировать проект
cd docs_search

# 2. Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 3. Установить Python зависимости
pip install -r requirements.txt

# 4. Установить системные утилиты для архивов (обязательно для RAR)
# Arch Linux:
sudo pacman -S unrar p7zip

# Ubuntu/Debian:
sudo apt-get install unrar p7zip-full

# Для создания RAR архивов (опционально, для генератора):
# Arch Linux:
yay -S rar
# Ubuntu/Debian:
sudo apt-get install rar
```

## Команды поиска

### Интерактивный режим
```bash
python search.py
```

Доступные команды:
- `/exit` — выход
- `/stats` — статистика по типам файлов в индексе
- Прямой ввод слова — поиск

### Прямой поиск
```bash
python search.py "финансовый"
python search.py "договор"
python search.py "техническое задание"
```

## Структура проекта

```
docs_search/

├── crawler.py                # Краулер (сканирование + парсинг + CSV)
├── create_db.py              # Создание БД (SQLite FTS5)

├── run.sh                    # Скрипт для полного запуска
├── requirements.txt          # Python зависимости
├── storage/                  # Хранилище файлов (создаётся)

│   └── archives/             # Архивы (.zip, .rar, .7z)
└── output/                   # Результаты работы
    ├── documents_index.csv   # CSV файл от краулера
    ├── search.db             # SQLite база данных
    └── full_texts.pkl        # Полные тексты (кэш для БД)
```

## Результаты работы

### Генерация документов

Программа создаёт:
- **50 документов** (10 тем × 5 форматов)
- **3 архива** (ZIP, RAR, 7z) с вложенными файлами
- Общий размер хранилища: ~800 KB

### CSV файл (`output/documents_index.csv`)

Содержит для каждого файла:
| Поле | Описание |
|------|----------|
| `file_path` | Полный путь к файлу |
| `file_name` | Имя файла |
| `file_type` | Расширение (doc, docx, pdf, zip и т.д.) |
| `file_size` | Размер в байтах |
| `content_preview` | Первые 500 символов содержимого |

### База данных (`output/search.db`)

- **Движок:** SQLite с расширением FTS5
- **Таблица:** `documents` (виртуальная FTS5)
- **Поля:** `content`, `file_name`, `file_type`, `file_path`
- **Токенизатор:** `unicode61` (полная поддержка русского языка)

## Устранение проблем

### Проблема: RAR архивы не создаются

```bash
# Установите rar через AUR (Arch Linux)
yay -S rar

# Или через apt (Ubuntu/Debian)
sudo apt-get install rar
```

### Проблема: Не парсятся RAR архивы

```bash
# Установите unrar (Arch Linux)
sudo pacman -S unrar

# Ubuntu/Debian
sudo apt-get install unrar
```

### Проблема: Не работают 7z архивы

```bash
# Установите p7zip (Arch Linux)
sudo pacman -S p7zip

# Ubuntu/Debian
sudo apt-get install p7zip-full
```

### Проблема: Ошибка "no such tokenizer: russian"

**Решение:** Исправлено в коде — используется `unicode61` вместо `russian`

### Проблема: Пустой результат поиска
